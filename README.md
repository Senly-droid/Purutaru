# プルタル（Purutaru）

第7回学力向上アプリコンテスト応募作品。

## 1. 作品名

**プルタル（Purutaru）**

## 2. 作品概要

### 目的・背景

世界史の教科書には、古代ギリシャ・ローマの人物が「名前と一行の実績」だけで
紹介されているだけの箇所が多くあります（例：タレス＝「イオニア学派の祖」）。
この一行だけでは人物像が記号的になり、暗記はできても記憶に残りにくい、
勉強としても面白みに欠けるという課題があります。

「プルタル」は、教科書の文化史一覧表に載っている人物を検索すると、
教科書的な実績に加えて、教科書には載らない**「もう一つの顔」**（意外な
エピソードや人間味のある逸話）を表示するWebアプリです。さらに、その人物が
歴史からいなくなったら何が失われるのかを、人物どうしの関係データから
計算して提示します。人物を「覚える対象」ではなく「つながりの中にいる人」
として捉え直すことで、暗記中心になりがちな文化史学習を、より楽しく、
印象に残るものにすることを目指しています。

### 対象・収録範囲

高校世界史の教科書「ギリシア文化一覧表」「ローマ文化一覧表」に掲載されている
人物を中心に、古代ギリシャ・ローマの人物**42人**と、その間の関係**137件**を
収録（今後追加できる設計）。関係データはすべてWikipedia（日本語版・英語版）の
記述を確認したうえで作成し、史実性に議論があるものは「〜と伝わる」「諸説ある」と
本文に明記しています。

### 主な機能

**人物検索**
名前（日本語・英語表記）で検索すると、教科書的な実績と「もう一つの顔」を
1枚のカードで表示します。出典（Wikipedia等）も明記します。収録人物の一覧は
ボタンひとつで表示・非表示でき、地域別・ジャンル別の絞り込みとお気に入り登録も
できます。

**もしこの人物がいなかったら**
137件の関係データをネットワーク（グラフ）として解析し、その人物が歴史から
消えた場合に何が失われるかを文章で自動生成します。直接影響を受けた人物、
影響が何世代先の何人まで連鎖するか、その人が書き残した記録・その人について
書かれた記録、論争や親交、そしてネットワーク全体への影響（媒介中心性の順位、
取り除いたときの平均距離の変化、孤立してしまう人物）までを示します。
教科書の一行だけでは見えない「その人の重み」を、数値と文章の両方で伝えます。

**クイズモード**
教科書の実績データをもとにした学習定着機能です。

- 出題形式：「実績→人物名」「人物名→実績」の2形式（ランダム混在も可）
- 出題範囲：地域別（ギリシャ／ローマ）、職業ジャンル別（哲学者・政治家など）
- 出題数：5／8／10／15問／全問から選択
- 制限時間：なし、または5〜20秒から選択（時間切れは不正解扱い）
- 「間違えた問題をもう一度」で、間違えた問題だけを再挑戦して弱点を復習
- クイズ履歴と通算正答率の記録（直近20回）

**人物相関図**
42人全員の関係を、力学モデルで自動配置したネットワーク図として表示します。
人物の点を押すとその人のつながりが強調され、線を押すと「タレス →(師である)→
ピタゴラス」のような矢印つきの図式と、関係の説明が表示されます。図は
ドラッグで移動、マウスホイールや2本指のピンチ、ボタンで拡大縮小できます。

**相性診断**
見た人物・お気に入り・質問への回答から興味の傾向を計算し、相性のいい人物を
上位3人まで提示します。ジャンルや地域の好みに加えて、相関図上でのつながりも
考慮して算出しています。履歴が少ないときは、4つの質問から傾向を推定します。

**一覧表で見る**
42人全員の「人物名」「実績」「もう一つの顔（簡略版）」を1つの表にまとめて見比べられます。
実績は教科書の文化史一覧表に書かれている語句・作品名などをもとにしています
（文章をそのまま書き写さず、該当する語句のみを抜き出して構成）。人物名・実績・
もう一つの顔（簡略版）の3列は、それぞれ独立してチェックボックスで表示・非表示を
切り替えられ、必要な情報だけに絞って見返せます。人物名を押すと、その人物の
詳細画面（出典つき）に移動します。

**読み上げ・表示設定（アクセシビリティ）**
ブラウザの音声合成機能を使った読み上げ（人物の解説・クイズの問題・診断結果）、
自動読み上げの切り替え、読み上げ速度の変更、文字サイズの3段階変更、
高コントラスト表示（黒地）に対応しています。すべての操作はキーボードの
TabキーとEnterキーだけでも行えます。設定はブラウザに保存されます。

### 独創性のポイント

教科書の記述を否定・置き換えるのではなく、教科書の記述を起点に「もう一つの顔」
を足すことで、暗記量を増やさずに興味と定着を高める設計にしています。

さらに、収録した人物関係をグラフ構造として扱い、影響の連鎖をたどる探索と
媒介中心性の計算によって「その人物がいなかったら何が失われるか」を文章として
自動生成する点が、単なる人物事典との大きな違いです。ネットワーク分析の手法を
歴史学習に持ち込むことで、人物どうしの関係を「暗記項目」ではなく「構造」として
理解できるようにしています。

検索して知る → クイズで覚える → 相関図と影響分析でつながりを俯瞰する →
相性診断で次に知りたい人物に出会う、という学習の循環を、1つのアプリの中で
完結させています。

### 動作方法

1. 検索欄に人物名（例：「ソクラテス」）を入力するか、「収録人物の一覧を表示」
   から人物を選ぶと、その人物の実績・「もう一つの顔」・「もしこの人物が
   いなかったら」・ほかの人物とのつながりが表示されます。
2. 「クイズに挑戦する」で出題形式・範囲・出題数・制限時間を選び、「この設定で
   始める」でクイズが始まります。結果画面から、間違えた問題だけの再挑戦や、
   同じ設定での再挑戦ができます。
3. 「相関図を見る」で42人の相関図が表示されます。点を押すとその人物のつながりが、
   線を押すと2人の関係の図式が表示されます。ドラッグで移動、ホイールやピンチ、
   右上のボタンで拡大縮小できます。
4. 「相性診断」で、あなたの興味に近い人物を診断します。
5. 「一覧表で見る」で、42人の人物名・実績・もう一つの顔（簡略版）を表で見比べられます。
   列ごとのチェックボックスで表示・非表示を切り替えられ、人物名を押すとその人物の
   詳細画面に移動します。
6. 「読み上げ・表示設定」で、音声読み上げ・文字サイズ・配色を変更できます。

### 対応環境

Webブラウザ（PC／タブレット／スマートフォン）で動作します。アプリのインストールは
不要で、URLを開くだけで利用できます。サーバーを使わない静的サイトのため、
Windows・macOS・Linux・Android・iPadOS・iOSのいずれでも、ブラウザさえあれば
同じように利用できます。音声読み上げは、ブラウザの音声合成機能に対応した環境で
利用できます。

## 3. 技術構成

サーバー（バックエンド）を使わず、検索・クイズ・相関図・グラフ解析・相性診断の
すべてをブラウザ上のJavaScriptで実装した、完全な静的サイトです。外部ライブラリも
使用していません（相関図のレイアウトとグラフ解析も自前で実装）。GitHub Pagesのみで
無料・常時稼働の公開ができます。

お気に入り・閲覧履歴・クイズ履歴・表示設定は、ブラウザのlocalStorageにのみ
保存されます。外部に送信されるデータはありません。

```
purutaru-pages/
├── index.html          アプリ本体（UI・検索・クイズ・相関図・解析・診断）
├── data/
│   ├── figures.js       人物データ（古代ギリシャ・ローマ 42人）
│   └── relations.js     人物どうしの関係データ（137件）
└── README.md
```

主なアルゴリズム

- 相関図の配置：反発力・ばね・中心引力による力学モデル（自前実装）
- 影響の連鎖：師弟・影響の関係を有向グラフとして幅優先探索
- 橋渡し度：Brandesのアルゴリズムによる媒介中心性
- ネットワークへの影響：人物を取り除いた前後の全点対最短距離の比較
- 相性診断：ジャンル・地域の重みづけベクトルと、相関図上の近さによるスコアリング

## GitHub Pagesでの公開手順（開発メモ）

1. GitHubで新しいリポジトリを作成する（例: `Purutaru`）
2. このフォルダの中身（`index.html`、`data/`、`README.md`）をリポジトリのルートに追加してpush

   ```bash
   cd purutaru-pages
   git init
   git add .
   git commit -m "プルタル: 影響分析・相性診断・相関図の操作・読み上げに対応"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/Purutaru.git
   git push -u origin main
   ```

   ※ GitHubのWeb UIから「Add file」→「Upload files」で
   `index.html`・`README.md`・`data/figures.js`・`data/relations.js`
   をアップロードする方法でも公開できます（`data/`の階層が保たれているか要確認）。

3. GitHubのリポジトリ画面で「Settings」→「Pages」を開く
4. 「Build and deployment」の「Source」で `Deploy from a branch` を選択
5. 「Branch」で `main` ブランチ、フォルダは `/ (root)` を選んで保存
6. 数分待つと `https://あなたのユーザー名.github.io/Purutaru/` で公開されます

## 人物データの追加方法

`data/figures.js` の配列に、以下の形式でオブジェクトを追加します。

```js
{
  id: "一意のID（英数字）",
  name: "表示名",
  name_en: "英語名（検索用）",
  category: "ギリシャ" または "ローマ",
  genre: "職業カテゴリ（哲学者、政治家・軍人 など）",
  achievement: "教科書に載っている一行実績（クイズの出題にも使用）",
  hidden_face: "教科書に載らない逸話・もう一つの顔",
  hidden_face_short: "hidden_faceを1〜2文に要約した簡略版（一覧表での表示用）",
  source: "出典の説明",
  source_url: "出典のURL",
}
```

`achievement` は、教科書の文化史一覧表（ギリシア文化一覧表・ローマ文化一覧表）に
書かれている用語・作品名などの短い語句を組み合わせて作成しており、教科書の文章を
そのまま書き写すことは避けています（著作権に配慮した抜粋方式）。

新しい人物を追加したら、`data/relations.js` にもその人物との関係を追加すると、
相関図・つながり・影響分析・相性診断のすべてに自動的に反映されます。

```js
{
  from: "起点となる人物のid",
  to: "対象の人物のid",
  type: "関係の種類（師弟／影響／友人／競合／論敵／政敵／記録）",
  label: "関係を説明する日本語の文（fromが主語になるように書く）",
  source_url: "出典のURL",
}
```

向きの規約は「labelの文の主語が `from`」です。たとえば `type: "師弟"` は
fromが師・toが弟子、`type: "影響"` はfromがtoから影響を受けた、という意味に
なります。この向きをもとに、相関図の矢印と影響の連鎖が計算されます。
