# プルタル（Purutaru）

第7回学力向上アプリコンテスト応募作品。

## 1. 作品名

**プルタル（Purutaru）**

## 2. 作品概要

### 目的・背景

世界史の教科書には、古代ギリシャ・ローマの人物が「名前と一行の実績」だけで
紹介されているだけの箇所が多くあります（例：タレス＝「イオニア学派の祖」）。
この一行だけでは人物像が記号的になり、暗記はできても記憶に残りにくい、
勉強としても面白みに欠けるという課題があります。

「プルタル」は、教科書の文化史一覧表に載っている人物を検索すると、
教科書的な実績に加えて、教科書には載らない**「もう一つの顔」**（意外な
エピソードや人間味のある逸話）を表示するWebアプリです。人物に対する
興味・記憶のきっかけを増やすことで、暗記中心になりがちな文化史学習を
より楽しく、印象に残るものにすることを目指しています。

### 対象・収録範囲

高校世界史の教科書「ギリシア文化一覧表」「ローマ文化一覧表」に掲載されている
人物を中心に、古代ギリシャ・ローマの人物**42人**を収録（今後追加可能な設計）。

### 主な機能

- **人物検索**：名前（日本語・英語表記）で検索すると、教科書的な実績と
  「もう一つの顔」を1枚のカードで表示。出典（Wikipedia等）も明記。
- **収録人物の一覧表示**：ボタン一つで42人の一覧を表示／非表示できる
  絞り込みチップ付きリスト（地域別・ジャンル別に絞り込み可能）。
- **お気に入り**：気になった人物を保存し、あとから見返せる（ブラウザ内保存）。
- **クイズモード**：教科書の実績データをもとにした学習定着機能。
  - 出題形式：「実績→人物名」「人物名→実績」の2形式（混在も可）
  - 出題範囲：地域別（ギリシャ／ローマ）、職業ジャンル別（哲学者・政治家など）
    の両方で絞り込み可能
  - 出題数：5／8／10／15問／全問から選択
  - 制限時間：なし、または5〜20秒の範囲で選択可能（タイムアウトは不正解扱い）
  - 「間違えた問題をもう一度」機能：間違えた問題だけを再挑戦し、弱点を復習できる
  - クイズ履歴の保存（直近20件）
- **人物相関図**：収録している42人全員について、師弟関係・思想的影響・友人・
  競合・論敵などの関係性を、力学的レイアウトによるネットワーク図として可視化。
  ノードをクリックすると、その人物とのつながりが一覧で表示される
  （例：「ソクラテスはプラトンの師である」「アリストテレスはプラトンの弟子」
  といった関係を、教科書の一行紹介だけでは見えにくい人物どうしのつながりとして
  俯瞰できる）。

### 独創性のポイント

- 教科書の記述を否定・置き換えるのではなく、教科書の記述を起点に
  「もう一つの顔」を足すことで、暗記量を増やさずに興味と定着を高める設計。
- クイズと相関図は同じ人物データ・関係データを土台にしており、
  「検索して知る」→「クイズで覚える」→「相関図でつながりを俯瞰する」という
  3段階の学習導線を1つのアプリの中で完結させている。
- サーバーを使わない完全静的サイトのため、無料・常時稼働で公開できる。

### 動作方法

1. 検索欄に人物名（例：「ソクラテス」）を入力するか、「収録人物の一覧を表示」
   から人物を選ぶと、その人物の実績と「もう一つの顔」が表示されます。
2. 「クイズに挑戦する」ボタンから出題形式・範囲・出題数・制限時間を選び、
   「この設定で始める」でクイズが始まります。結果画面から間違えた問題だけの
   再挑戦や、同じ設定でのもう一度の挑戦ができます。
3. 「相関図を見る」ボタンから、42人の人物相関図が表示されます。ノード
   （人物）をクリックすると、その人物を中心にしたつながりがハイライトされ、
   関係の一覧が下に表示されます。

### 対応環境

Webブラウザ（PC／タブレット／スマートフォン）で動作します。特別なアプリの
インストールは不要です。サーバーを使わない静的サイトのため、
Windows・macOS・Linux・Android・iPadOS・iOSいずれの端末でも、ブラウザさえ
あれば同じように利用できます。

## 3. 技術構成

サーバー（バックエンド）を使わず、検索・クイズ・相関図のロジックをすべて
JavaScriptで実装した完全静的サイトです。GitHub Pagesのみで無料・常時稼働の
公開ができます。

```
purutaru-pages/
├── index.html          アプリ本体（UI・検索・クイズ・相関図ロジック）
├── data/
│   ├── figures.js       人物データ（古代ギリシャ・ローマ 42人）
│   └── relations.js     人物どうしの関係データ（137件）
└── README.md
```

## GitHub Pagesでの公開手順（開発メモ）

1. GitHubで新しいリポジトリを作成する（例: `Purutaru`）
2. このフォルダの中身（`index.html`、`data/`、`README.md`）をリポジトリのルートに追加してpush

   ```bash
   cd purutaru-pages
   git init
   git add .
   git commit -m "プルタル: クイズ機能拡張・相関図を追加"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/Purutaru.git
   git push -u origin main
   ```

   ※ GitHubのWeb UIから「Add file」→「Upload files」で
   `index.html`・`README.md`・`data/figures.js`・`data/relations.js`
   をアップロードする方法でも公開できます（`data/`の階層が保たれているか要確認）。

3. GitHubのリポジトリ画面で「Settings」→「Pages」を開く
4. 「Build and deployment」の「Source」で `Deploy from a branch` を選択
5. 「Branch」で `main` ブランチ、フォルダは `/ (root)` を選んで保存
6. 数分待つと `https://あなたのユーザー名.github.io/Purutaru/` で公開されます

## 人物データの追加方法

`data/figures.js` の配列に、以下の形式でオブジェクトを追加します。

```js
{
  id: "一意のID（英数字）",
  name: "表示名",
  name_en: "英語名（検索用）",
  category: "ギリシャ" または "ローマ",
  genre: "職業カテゴリ（哲学者、政治家・軍人 など）",
  achievement: "教科書に載っている一行実績（クイズの出題にも使用）",
  hidden_face: "教科書に載らない逸話・もう一つの顔",
  source: "出典の説明",
  source_url: "出典のURL",
}
```

新しい人物を追加した場合、`data/relations.js` にもその人物との関係を
追加すると、相関図・つながりカードに反映されます（形式は同ファイル内の
コメントを参照）。

```js
{
  from: "起点となる人物のid",
  to: "対象の人物のid",
  type: "関係の種類（師弟／影響／友人／競合／論敵／政敵／記録）",
  label: "関係を説明する日本語の文（fromが主語になるように書く）",
  source_url: "出典のURL",
}
```
